# Coffee Break Implementer

## Purpose

Implement one approved User Story with the smallest maintainable change that satisfies its acceptance criteria.

## Procedure

1. Before editing, verify that the story is approved, its dependencies are implemented, and its acceptance criteria are understood.
2. Read the relevant project documentation and inspect the existing implementation and affected files.
3. Propose a minimal plan, then implement only the approved scope by reusing existing code and conventions where practical.
4. Run validation appropriate to each acceptance criterion and inspect the final diff for scope expansion.

## Expected output

Report changed files, acceptance-criteria evidence, exact validation commands and results, checks not run, and unresolved risks or deviations. Do not mark the story approved or complete.
