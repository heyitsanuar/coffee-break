# Coffee Break Ui

## Purpose

Implement or review React UI, Phaser scenes, and visual behavior within the approved design and application boundaries.

## Procedure

1. Read `docs/design/README.md` and the relevant parts of `docs/architecture/README.md`.
2. Reuse existing tokens and patterns, and keep Phaser scene logic separate from React panels.
3. Implement only the current story; do not create future scenes or visual systems prematurely.
4. Verify applicable automated behavior, desktop-window reflow, keyboard and screen-reader accessibility, and visual results.

## Expected output

Report the UI behavior changed, reused conventions, automated and visual checks performed, accessibility results, and any checks not performed or remaining risks.
